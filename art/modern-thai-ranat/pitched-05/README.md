# Ranat 05 — graduated playable bars

ปรับลูกระนาด 21 ลูกให้ไล่ความยาว 360 → 270 มม. จากซ้ายไปขวาของผู้เล่น (ผู้เล่นอยู่ด้าน -Y, เสียงสูงขึ้นตาม +X) ลดลูกละ 4.5 มม. เพื่อให้ผืนเข้ากับขนาดโมเดลเดิม

ลำดับชื่อเสียง: ซ ล ท ด ร ม ฟ / ซ ล ท ด ร ม ฟ / ซ ล ท ด ร ม ฟ โดยแต่ละกลุ่มสูงขึ้นหนึ่งช่วงคู่แปด กำหนด pitch_rank 1–21 และ note_index 0–20 ในวัตถุแต่ละลูก รวมถึงใน GLB extras ดู note-map.json

อ้างอิงลำดับเสียงและทิศทางการเรียงจากชุดฝึกระนาดเอกของครูรณชัย บุญลือ โรงเรียนบางขุนเทียนศึกษา: https://pubhtml5.com/cbfya/gkvc/basic/51-100 และ https://pubhtml5.com/cbfya/gkvc/basic/

ปรับเชือกสองแนวและห่วงร้อยให้ตามรูของลูกระนาดใหม่ ราง โขน ขา ไม้แทรก วัสดุ และไม้ตีใช้ geometry เดิม ตรวจ 41 mesh ที่อยู่นอกระบบลูกระนาด/เชือกแล้วตำแหน่ง vertex และ transform เท่าเดิม

ขนาดรวม 1398.304 × 360 × 349.099 มม. ทั้ง GLB และ FBX นำกลับเข้า Blender แล้วตรวจจำนวนลูก ลำดับความยาว ขนาด และ texture ผ่าน GLB ผ่าน validator โดยไม่มี error/warning

ค่าความยาวเป็นขนาดสำหรับโมเดลภาพ ไม่ใช่การคำนวณปรับเสียงจริง ชื่อเสียงระบุลำดับสำหรับผูกกับ sample ภายหลัง ยังไม่มีการกำหนดความถี่ Hz หรือเพิ่มระบบเล่นเสียง และไม่ได้อัปเดตเว็บไซต์
