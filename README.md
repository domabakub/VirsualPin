# Virtual Pin

แพลตฟอร์มเรียนรู้การเล่นพิณไทยด้วย AI, Computer Vision และ AR โดยทำงานผ่านเว็บเบราว์เซอร์ ไม่ต้องใช้เซนเซอร์ ถุงมือ หรืออุปกรณ์เสริม

## แผนพัฒนา 4 Milestones

1. **Camera & Hand Tracking** — เปิดกล้อง ตรวจจับมือซ้าย/ขวา 21 จุด และลดอาการ landmark สั่น
2. **Virtual Pin & Audio** — พิณเสมือน 3D, fret/string mapping และเสียงตอบสนองทันที
3. **AI Coach** — ประเมินนิ้ว การดีด จังหวะ และแนะนำการแก้ไขแบบ real-time
4. **Learning Platform** — บทเรียน เพลง คะแนน ประวัติ และ Dashboard สำหรับผู้เรียน/ครู

ต้นแบบปัจจุบันครอบคลุม Camera/Hand Tracking และ user flow สำหรับทดลองใช้งานจริงตั้งแต่หน้า Home เลือกเพลง ไปจนถึงหน้าฝึกกับพิณเสมือน

## หน้าจอและเส้นทางหลัก

- `/` — Home Dashboard และทางเข้าโหมดต่าง ๆ
- `/songs` — คลังเพลงตัวอย่าง 6 เพลง พร้อมค้นหา ตัวกรอง และความคืบหน้า
- `/play/[slug]` — ฝึกสายและเฟรต พร้อมโน้ตปัจจุบัน โน้ตถัดไป และสรุปคะแนน
- `/play/free-play` — เล่นพิณอิสระโดยไม่ตรวจลำดับเพลง
- `/studio` — บันทึกพิณ 8 ห้อง แก้โน้ต ใส่ Drum Loop และ Export WAV/MIDI
- `/settings` — หน้าตั้งค่าพื้นฐาน

## Virtual Pin ที่ใช้งานได้

- เลือกเฟรต 0–6 และดีดพิณ 3 สายด้วยหน้าจอสัมผัส
- เปิดปุ่มลัดคีย์บอร์ด `1`, `2`, `3` สำหรับดีดสายได้ในหน้าตั้งค่า (ปิดเป็นค่าเริ่มต้น)
- สังเคราะห์เสียงแบบ low-latency ด้วย Web Audio API โดยไม่ต้องดาวน์โหลดไฟล์เสียง
- ตรวจสายและเฟรต ให้คำแนะนำ คะแนน และสรุปเมื่อเล่นครบ โดยยังไม่ประเมินจังหวะ
- บันทึกความคืบหน้าและการตั้งค่าในเบราว์เซอร์นี้ พัก/ฝึกต่อและรีเฟรชได้ ไม่ซิงก์ข้ามเครื่อง
- ชื่อโน้ตและเสียงใช้การตั้งสายเดียวกัน E4 / A3 / E3; เพลงในคลังเป็นแบบฝึกทดสอบ ยังไม่ใช่ทำนองต้นฉบับที่ตรวจสอบแล้ว
- เมโทรนอมตาม BPM ของแต่ละเพลง
- เมื่อเปิดกล้อง มือซ้ายควบคุมตำแหน่งเฟรต และการจีบนิ้วมือขวาใช้ดีดสาย

## Studio Mode MVP

- บันทึกโน้ตจากปุ่มสัมผัสหรือ Hand Tracking พร้อม Count-in 1 ห้อง
- แสดงโน้ตบน Timeline 8 ห้อง เล่นย้อนหลัง และจัดจังหวะเป็น 1/8 หรือ 1/16
- เลือกโน้ตเพื่อแก้สาย เฟรต และน้ำหนักการดีด
- เพิ่ม Isan Demo Beat พร้อม Volume และ Mute แยกแทร็ก
- Auto-save โปรเจกต์ในเบราว์เซอร์ และ Export เป็น WAV หรือ MIDI

ขั้นตอนเดโมและภาพหน้าจอ: [Studio Mode MVP](./docs/studio-mvp/README.md)

## ความสามารถใน Milestone 1

- เปิด/หยุดกล้องจาก browser และสลับกล้องหน้า/หลัง
- รองรับกล้องบน iOS, iPadOS, Android, Windows และ macOS
- ตรวจจับได้สูงสุด 2 มือด้วย MediaPipe Hand Landmarker
- แยกมือซ้าย/ขวา พร้อม confidence
- แสดง landmark 21 จุดและโครงกระดูกมือบนภาพกล้องแบบ mirrored
- ลด jitter ด้วย Exponential Moving Average
- GPU acceleration และ fallback ไป CPU อัตโนมัติ
- ประมวลผลภาพภายใน browser โดยไม่ส่งวิดีโอขึ้น server
- หน้าหลัก คลังเพลง และหน้าฝึกรองรับมือถือ พร้อมปุ่มสัมผัสและตัวบอกโฟกัสคีย์บอร์ด

## เริ่มใช้งาน

ดูขั้นตอนละเอียดใน [INSTALLATION.md](./INSTALLATION.md)

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` แล้วเลือกเพลงหรือโหมดเล่นอิสระ ใช้ปุ่มหน้าจอได้ทันที และเปิดกล้องได้เมื่อต้องการ

## คำสั่งตรวจสอบ

```bash
npm run lint
npm test
npm run typecheck
npm run build
```

ชุดทดสอบใช้ Node.js 22.20 ขึ้นไป ตรวจการตั้งสาย คะแนน การอ่านข้อมูลที่เสียหาย และกรณีบันทึกถาวรไม่ได้ หากตรวจชนิดข้อมูลหลังเปลี่ยนเส้นทางแล้วพบไฟล์ประเภทที่สร้างไว้เก่า ให้รัน build เพื่อสร้างใหม่

รายละเอียดการแก้ UX/UI และผลทดสอบ: [Implementation report](./docs/ui-audit-2026-08-31/IMPLEMENTATION.md)

ดีไซน์ล่าสุดแนวเรียบ พร้อมฟอนต์ใหม่และภาพถ่ายพิณจริง: [Visual refresh](./docs/ui-refresh-2026-08-31/README.md)
