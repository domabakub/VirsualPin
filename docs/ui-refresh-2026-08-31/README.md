# Virtual Pin — Visual refresh

ปรับตามคำขอให้เรียบในแนว Apple และใช้ภาพถ่ายจริง โดยคงระบบฝึกและการบันทึกผลเดิมไว้

## เปลี่ยนอะไร

- พื้นขาว เทากลาง และตัวอักษรดำ ลดกรอบ เงา และภาพตกแต่งซ้ำ ใช้สีน้ำเงินเฉพาะการกระทำสำคัญ
- ฟอนต์ไทย IBM Plex Sans Thai และอังกฤษ Inter แบบ self-hosted รวมไฟล์ WOFF2 ประมาณ 82 KB ไม่ใช้ฟอนต์ San Francisco หรือภาพจาก Apple
- หน้าแรกใช้หัวเรื่องขนาดใหญ่ พื้นที่ว่าง และ Sketchfab Viewer สำหรับโมเดลพิณ 3 มิติ พร้อมแบ่งส่วนเริ่มเล่น / เรียน / แบบฝึก
- คลังเพลงเปลี่ยนเป็นรายการเพลงที่อ่านง่ายพร้อมค้นหา ตัวกรอง และความคืบหน้าจริง
- เมนูเดสก์ท็อปย้ายขึ้นด้านบน มือถือคงเมนูด้านล่าง
- หน้าฝึกใช้แผงโน้ตสีดำและปุ่มควบคุมเรียบ ลดกรอบซ้อน ไม่เปลี่ยนตรรกะคะแนน/เสียง
- ตั้งค่าเป็นกลุ่มรายการและสวิตช์ที่กดได้จริง
- ลบภาพพิณที่วาดด้วย SVG/CSS ออกจากหน้าที่ใช้งาน ส่วน hero ใช้โมเดล Sketchfab ที่ผู้ใช้ระบุ และเส้นเฟรตบนกล้องเป็นเครื่องมือช่วยเล่น ไม่ใช่ภาพจำลองเครื่องดนตรี

## ภาพจริงและฟอนต์

หน้าแรกแสดงภาพถ่ายพิณจริงจาก Wikimedia Commons เป็นค่าเริ่มต้น ปุ่ม “โมเดล 3 มิติ · กดเพื่อสำรวจ” จะสลับเป็น [พิณ โดย suphanburiworldmusic บน Sketchfab](https://sketchfab.com/3d-models/80e48aa96fe4452f952537cd0b638d98) ผ่าน viewer ทางการพร้อมเครดิตและ `dnt=1` โดยไม่ดาวน์โหลดหรือแก้ไฟล์โมเดล หากเครื่องแสดง 3D ไม่ได้ สามารถกลับสู่ภาพตัวอย่างได้ ภาพพิณโบราณจาก [The Met](https://www.metmuseum.org/art/collection/search/500840) ระบุ Public Domain และใช้พร้อมคำบรรยายว่าเป็นเครื่องดนตรีในอดีต

ไม่มีการใช้ AI สร้างหรือแก้โมเดล 3 มิติ ภาพถ่ายที่ยังใช้อยู่มีเครดิตใน footer และรายละเอียดใน [CREDITS.md](../../public/images/CREDITS.md) ส่วนฟอนต์มีใบอนุญาต OFL ใน [public/fonts](../../public/fonts/README.md)

## ตรวจแล้ว

- 6 เส้นทางที่ 320 / 390 / 768 / 1440px: ไม่ล้นแนวนอน ทุกหน้ามี main เดียว ดู [ผลวัด](./responsive-checks.json)
- เล่นครบ 12 โน้ต ได้ 1,200 คะแนน / 100%; พักและ reload แล้วฝึกต่อได้ จากนั้นล้างเฉพาะผลที่ใช้ทดสอบผ่านปุ่มเริ่มใหม่
- ตัวกรองคงอยู่หลัง reload ค้นหาไม่พบแล้วล้างกลับได้
- เปลี่ยนกล้องเริ่มต้น ระดับเสียง และสวิตช์ปุ่มลัดแล้ว reload ค่ายังอยู่ คืนค่าทดสอบเป็นกล้องหน้า / 80% / ปุ่มลัดปิด
- โฟกัสคีย์บอร์ดที่ช่องค้นหาเห็น outline สีน้ำเงิน 3px
- ผ่าน `npm test` ทั้ง 8 รายการ, `npm run lint`, `npm run typecheck`, `npm run build`
- ตรวจภาพจริงจาก production build ใน Chromium; ไม่ได้ทดสอบกล้องจริง, Safari หรือ screen reader จริง และไม่ได้ deploy
