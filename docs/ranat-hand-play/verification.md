## ข้อจำกัดของหลักฐาน

- กล้องเป็น fake camera ของ browser ไม่ใช่มือจริง ยังไม่ได้ยืนยันความแม่น การตีเร็ว การไขว้มือ หรือ handedness กับกล้องผู้ใช้
- ตัวเลข FPS ของ fake camera ไม่ใช้แทนผลวัดอุปกรณ์เดโมจริง
- ตรวจการสร้างและบันทึก event รวมถึงการเรียก audio runtime แต่ยังไม่ได้วัดความหน่วงจากลำโพง/หูฟังจริง
- Console มี 404 ของ favicon.ico ที่ขาดอยู่เดิม รายงาน URL ไว้ใน browser-report.json; ไม่มี page runtime exception ระหว่าง flow ที่ทดสอบ
- โมเดลเป็นต้นแบบอ้างอิงรูปทรงและสี ยังไม่มีลายประดับครบทุกจุดของภาพ reference

## ลองด้วยมือจริง

เปิด `/instruments/ranat/play` → กล้อง → เปิดกล้อง → รอระบบพร้อม → เริ่มจับมือ ยกฝ่ามือเหนือเส้นเขียว เลื่อนซ้าย–ขวา แล้วลดผ่านเส้นทอง หากพื้นที่มือไม่พอดี ให้ใช้ตั้งพื้นที่เล่น 4 ขั้น โดยแต่ละขั้นมีเวลา 2 วินาทีให้วางเมาส์และจัดมือ

ให้เริ่มจาก “ตีเอง” ช่วงกลางก่อน แล้วลองกรอช่วยด้วยมือเดียว สังเกตว่ามือหายแล้วเสียงกรอหยุด และมือกลับเข้าต่ำไม่เริ่มเสียงเอง
