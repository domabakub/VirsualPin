# Self-hosted fonts

- Inter, Latin variable subset, weights 400–700.
- IBM Plex Sans Thai, Thai subset, weights 400, 500, 600.
- Downloaded from Google Fonts on 2026-08-31. Original CSS URLs are recorded in
  source.css.txt. Only Latin Inter and Thai IBM Plex Sans Thai subsets are used.
- Licensed under SIL Open Font License 1.1. See the accompanying license files.
- Served locally using next/font/local. Visitors do not request Google Fonts.
- These are open fonts, not Apple's proprietary San Francisco font.
